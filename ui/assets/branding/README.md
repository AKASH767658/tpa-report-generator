# Branding assets

The live dashboard and downloaded HTML report both use the files in this folder.

- Replace `logo.svg` with your logo file, or add a PNG/JPG/SVG file here and set its filename as `logo_file` in `branding.json`.
- Update `company_name` and `product_name` in `branding.json` to change the header text.
- Update the five entries under `colors` in `branding.json` to apply your brand palette everywhere.

Restart or refresh the Streamlit app after editing these files.
